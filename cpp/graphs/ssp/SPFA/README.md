# SPFA — Shortest Path Faster Algorithm

## Задача

Найти кратчайшие пути от одной вершины `s` до всех остальных во взвешенном графе, в том числе с **отрицательными рёбрами**.

---

## Идея

Bellman-Ford релаксирует все рёбра V-1 раз подряд — большинство релаксаций бесполезны. SPFA оптимизирует это наблюдением:

> Релаксация ребра `u→v` может улучшить `d[v]` только если `d[u]` недавно изменилось.

Поэтому держим очередь вершин, расстояние до которых обновилось, и обрабатываем только их соседей.

---

## Алгоритм

```
d[s] = 0, d[v] = ∞ для всех v ≠ s
добавить s в очередь, in_queue[s] = true

пока очередь не пуста:
    u = взять из очереди
    in_queue[u] = false

    для каждого ребра u→v с весом w:
        если d[u] ≠ ∞ и d[u] + w < d[v]:
            d[v] = d[u] + w
            prev[v] = u
            если v не в очереди:
                добавить v в очередь
                in_queue[v] = true
```

## Сложность

| Случай | Сложность |
|---|---|
| Средний | O(E) — на практике |
| Худший | O(V · E) — как Bellman-Ford |

Худший случай достигается на специально сконструированных тестах, поэтому SPFA ненадёжен на соревнованиях где тесты могут быть злыми.

---

## Корректность

**Почему работает с отрицательными рёбрами:**
Dijkstra жадно фиксирует `d[v]` навсегда — с отрицательными рёбрами это неверно, так как позже может найтись более короткий путь. SPFA не фиксирует ничего: если `d[v]` улучшилось, вершина снова идёт в очередь и её соседи пересчитываются.

**Почему завершается без отрицательных циклов:**
Каждая вершина входит в очередь не более V-1 раз — ровно столько итераций нужно Bellman-Ford для сходимости. Если какая-то вершина входит V-й раз — найден отрицательный цикл.

---

## Детекция отрицательных циклов

Считаем сколько раз каждая вершина входила в очередь. Если какая-то вершина вошла `n` или более раз — в графе есть отрицательный цикл, достижимый из источника.

```cpp
vector<int> count(n, 0);
// при добавлении в очередь:
count[v]++;
if (count[v] >= n) return true; // отрицательный цикл
```

---

## Сравнение с другими алгоритмами

| Алгоритм | Сложность | Отрицательные рёбра | Отрицательные циклы |
|---|---|---|---|
| Dijkstra | O(E log V) | ✗ | ✗ |
| Bellman-Ford | O(V · E) | ✓ | Детектирует |
| SPFA | O(E) средн. | ✓ | Детектирует |

## Применение в MCMF

В задаче **Min-Cost Max-Flow** SPFA используется для поиска кратчайшего пути по стоимости в остаточной сети. Остаточная сеть всегда содержит обратные рёбра с отрицательным весом `-w`, поэтому Dijkstra без потенциалов неприменима.

Отличия SPFA для MCMF от обычного SSSP:

- Релаксируем только рёбра с ненулевой остаточной пропускной способностью (`cap - flow > 0`)
- Детектор отрицательных циклов не нужен — в корректной сети потоков их нет по построению
- Дополнительно храним `prev_edge[v]` — индекс ребра, а не только вершину — чтобы обновлять поток

```cpp
if (e.rem_flow() > 0 && d[u] != LLONG_MAX && d[u] + e.w < d[e.to]) {
    d[e.to] = d[u] + e.w;
    prev_v[e.to] = u;
    prev_edge[e.to] = i; // индекс ребра в списке рёбер
    // ...
}
```
