# Min-Cost Max-Flow (MCMF)

## Постановка задачи

Дана **сеть потоков** — ориентированный граф G(V, E) с:
- Источником **s** — вершина, из которой течёт поток
- Стоком **t** — вершина, в которую течёт поток
- Пропускной способностью **cap(u, v)** — максимальный поток через ребро
- Стоимостью **w(u, v)** — стоимость единицы потока через ребро

**Цель:** найти максимальный поток из s в t минимальной суммарной стоимости.

Суммарная стоимость потока:
```
cost = Σ f(u, v) · w(u, v)  для всех рёбер
```

---

## Ограничения на поток

Поток `f(u, v)` должен удовлетворять двум условиям:

**Ограничение мощности** — поток не превышает пропускную способность ребра:
```
0 ≤ f(u, v) ≤ cap(u, v)
```

**Сохранение потока** — для каждой вершины кроме s и t сумма входящих потоков равна сумме исходящих:
```
Σ f(u, v) = Σ f(v, w)  для всех v ≠ s, t
```

---

## Остаточная сеть

Остаточная сеть показывает сколько потока ещё можно пустить или вернуть. Для каждого ребра `u→v` с потоком f, ёмкостью cap и весом w:

- **Прямое ребро:** остаток `cap - f`, стоимость `+w`
- **Обратное ребро:** остаток `f`, стоимость `−w`

Обратное ребро с отрицательной стоимостью позволяет "отменить" ранее пущенный поток — это механизм исправления ошибок алгоритма.

---

## Теорема Макс-поток / Мин-разрез

> Максимальный поток равен минимальному разрезу.

**Разрез (S, T)** — разбиение вершин на два множества (s ∈ S, t ∈ T). Пропускная способность разреза — сумма `cap(u, v)` для рёбер из S в T. Минимальный разрез даёт верхнюю границу максимального потока.

---

## Выпуклость стоимости

Стоимость потока является **выпуклой функцией** от его величины: каждая следующая единица потока стоит не дешевле предыдущей. Это свойство гарантирует корректность жадного подхода — всегда выгодно пускать поток по самому дешёвому доступному пути.

## Типовые задачи

| Задача | Сведение |
|---|---|
| Задача о назначениях | Двудольный граф, все ёмкости = 1, веса = стоимости назначений |
| Транспортная задача | Источники с предложением, стоки со спросом |
| Паросочетание минимальной стоимости | SSP на двудольном графе |
| Расписание с минимальной стоимостью | Задания как рёбра с весами |

---

## Отрицательные циклы

Если исходный граф содержит отрицательный цикл — задача некорректна, так как стоимость можно уменьшать бесконечно. В корректно построенной сети потоков отрицательных циклов нет по построению: обратные рёбра имеют вес `-w`, но цикл `u→v→u` имеет суммарный вес `w + (−w) = 0`.
