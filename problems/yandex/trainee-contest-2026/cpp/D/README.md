# D. Два множества

## Условие

Дано `N = 40` десятизначных чисел. Необходимо найти **два непустых
непересекающихся подмножества с одинаковой суммой**.

## Ограничения

| Параметр | Значение |
|---|---|
| `N` | ровно `40` |
| Числа | 10-значные (до `9 999 999 999`) |
| Время | 1 с |
| Память | 256 МБ |

## Формат ввода

На первой (и единственной) строке расположены `N` десятизначных чисел,
разделённых пробелами.

## Формат вывода

Выведите **4 строки** — по две на каждое множество. Для каждого множества:

1. Первая строка — одно число, мощность множества (количество элементов).
2. Вторая строка — само множество: **индексы** элементов входного файла
   (по нумерации задачи, как видно из примера — 1-индексация).

## Пример

**Ввод**

```
1000000000 1000000002 1000000003 2000000005 1000000099 1000000099 1000000099 1000000099 1000000099 …
```

**Вывод**

```
10
3 4 10 11 16 21 23 27 28 38
10
1 12 14 15 19 22 29 32 39 40
```

(Два множества по 10 элементов, суммы которых совпадают; индексы не
пересекаются.)

## Почему решение всегда существует

Это следствие **принципа Дирихле** («голубей и ящиков»).

* Число непустых подмножеств из 40 элементов: `2⁴⁰ − 1 ≈ 1.1 · 10¹²`.
* Максимально возможная сумма подмножества: `40 · 9 999 999 999 ≈ 4 · 10¹¹`,
  то есть различных значений суммы меньше, чем `4 · 10¹¹`.

Подмножеств почти втрое больше, чем возможных значений суммы, поэтому
обязательно найдутся **два разных подмножества `A` и `B` с равной суммой**.

Если `A` и `B` пересекаются, удалим из обоих их общую часть `A ∩ B`. Суммы
уменьшатся на одну и ту же величину, поэтому равенство сумм сохранится, а
множества `A \ B` и `B \ A` уже не пересекаются. Они остаются непустыми, так
как `A ≠ B` (если бы одно из них опустело, второе из-за равенства сумм тоже
было бы пустым, а это означало бы `A = B`).

## Идея решения

Полный перебор всех `2⁴⁰` подмножеств не помещается в лимит времени.
Используется **meet-in-the-middle**.

1. Делим 40 чисел на две половины по 20 элементов.
2. Для каждой половины перебираем все `2²⁰ ≈ 10⁶` подмножеств и считаем их
   суммы. Получаем два списка пар `(сумма, маска подмножества)`.
3. Ищем два подмножества с одинаковой суммой. Удобный приём — рассматривать
   разности: для каждой суммы `s` нам нужны два набора, дающие одинаковое
   значение. Реализуется через хеш-таблицу `сумма → маска`: при переборе
   подмножеств (или их комбинаций из двух половин) при первом же повторе суммы
   мы нашли искомую пару `A, B`.
4. Получив `A` и `B`, удаляем общие элементы и выводим индексы оставшихся
   элементов каждого множества.

Поскольку `2²⁰ ≈ 10⁶`, такой перебор укладывается в ограничения по времени и
памяти.

### Замечание о реализации хеш-таблицы

При генерации подмножеств одной половины можно складывать суммы в словарь
`dict[сумма] = маска`. Как только встречается сумма, уже присутствующая в
словаре, две соответствующие маски и образуют пару подмножеств с равной
суммой. При работе с двумя половинами используется тот же приём для сумм вида
`(сумма левой части) − (сумма правой части)`.

## Сложность

| | |
|---|---|
| Время | `O(2^{N/2})` ≈ `10⁶` операций |
| Память | `O(2^{N/2})` под хеш-таблицу сумм |

```bash
python3 solution.py < input.txt > output.txt
```
