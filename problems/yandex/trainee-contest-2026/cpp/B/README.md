# B. Осыпающийся песок

## Условие

Динозавр Дино чистит террариум от камней магнитом. В террариуме есть песок и
камни (магнитятся). Нужно написать функцию, которая вынет магнитом все камни и
оставит только песок (осевший по правилам гравитации и пересыпания).

## Ограничения

| Параметр | Значение |
|---|---|
| `1 ≤ h ≤ 10⁶` | высота террариума |
| `1 ≤ w ≤ 10⁶` | ширина террариума |
| `h × w ≤ 10⁶` | суммарный размер |
| Время | 1 с |
| Память | 64 МБ |

## Формат ввода

```
h
w
<двумерный массив h × w>
```

Массив состоит из песчинок (символ `0`) и камешков (символ `x`), элементы в
строке разделены пробелами.

## Формат вывода

Двумерный массив `h × w`, состоящий из песчинок (символ `0`) и пустых ячеек
(символ `-`).

## Правила (Примечание)

Камешки вытаскиваются постепенно **слева направо**. Пока все камешки не убраны
из текущего столбца, Дино не переводит магнит на следующий столбец.

Внутри столбца камешки вытаскиваются **сверху вниз** (от самого верхнего к
самому нижнему) по таким правилам:

* песчинки могут двигаться только **вниз**;
* песчинки **не** перемещаются наверх, даже когда камешки движутся вверх
  (считается, что камешки проходят вверх сквозь песчинки);
* все песчинки под действием гравитации падают вниз в своём столбце;
* песчинки из соседних столбцов слева и справа падают в текущий столбец, если
  **разница в высоте больше единицы**;
* сначала падают песчинки справа, потом слева — в текущую ячейку.

## Примеры

**Пример 1**

```
Ввод                 Вывод
4                    - - - - -
5                    0 0 0 - -
0 0 0 0 x            0 0 0 0 0
0 x x 0 0            0 0 0 0 0
0 x 0 x 0
x 0 0 x 0
```

**Пример 2**

```
Ввод                 Вывод
3                    - - - - -
5                    - - - - -
x x x x x            0 - 0 0 -
0 x x 0 0
x x x x x
```

**Пример 3** — весь террариум из камней превращается в пустой:

```
Ввод                 Вывод
3                    - - - - -
5                    - - - - -
x x x x x            - - - - -
x x x x x
x x x x x
```

## Идея решения

Камней нет в выводе, а песок **сохраняется** (во всех примерах суммарное число
песчинок не меняется) — он лишь оседает и пересыпается между столбцами.

Моделируется процесс в порядке обработки столбцов **слева направо**. Для
текущего столбца последовательно (сверху вниз) удаляются камни; при этом:

1. **Гравитация в столбце** — после удаления камня песчинки над ним оседают вниз
   (вверх песок не идёт).
2. **Боковое пересыпание** — пока разница высот песка между текущим столбцом и
   соседним больше 1, песчинка пересыпается в текущий столбец; **сначала**
   проверяется правый сосед, **потом** левый.
3. Шаги повторяются, пока столбец не «устаканится», после чего магнит переходит
   к следующему столбцу.

Так как `h × w ≤ 10⁶`, поле небольшое по суммарному размеру. Эффективная
реализация хранит для каждого столбца количество песка (высоту) и пересчитывает
перетоки локально между соседями, что позволяет уложиться в лимиты времени и
памяти.

### Замечания по реализации

* Удобно работать не с самим двумерным массивом посимвольно, а с **высотами
  столбцов** (число песчинок) — после оседания песок в столбце всегда занимает
  нижние ячейки. Камни в ещё не обработанных столбцах при этом нужно учитывать,
  так как они влияют на то, как оседает и перетекает песок.
* При формировании вывода нижние `height[c]` ячеек столбца `c` — это `0`,
  остальные — `-`.
* Поле может быть «вытянутым» (`h` или `w` до `10⁶` при их произведении до
  `10⁶`), поэтому ввод/вывод стоит делать быстрым (буферизованное чтение и
  запись).

## Сложность

| | |
|---|---|
| Время | `O(h · w)` при аккуратной реализации перетоков |
| Память | `O(h · w)` (или `O(w)`, если хранить только высоты столбцов) |
