# A. Дино в компьютерной игре

## Условие

Дино играет в «Бег с препятствиями» вслепую: он совершает прыжки строго по
заданному списку, не видя дорожки. Нужно подсчитать, сколько очков он
заработает, исходя из конфигурации трассы и его прыжков. Если трасса содержит
ошибки (невалидна) — результат **0 очков**.

## Ограничения

| Параметр | Значение |
|---|---|
| `n < 10⁵` | число препятствий |
| `m < 10⁵` | число прыжков |
| координаты `aᵢ, xᵢ` | `1 ≤ … < 10⁶` |
| тип препятствия `bᵢ` | `1 ≤ bᵢ ≤ 3` |
| дальность прыжка `yᵢ` | `yᵢ ∈ {1, 2, 4}` |
| Время | 1 с |
| Память | 128 МБ |

## Правила игры

**Как играет Дино:**
* прыгает мгновенно по команде и может прыгнуть мгновенно после приземления;
* получает очки за каждое успешно преодолённое препятствие (даже если за один
  прыжок их несколько);
* не может прыгнуть в воздухе — чтобы прыгнуть снова, нужно приземлиться;
* Дино не просят подпрыгивать в полёте.

**Очки за препятствия:**

| Препятствие | Тип `b` | Длина | Очки |
|---|---|---|---|
| Камень | 1 | 1 м | +1 |
| Бревно | 2 | 2 м | +3 |
| Яма | 3 | 4 м | +5 |

**Штрафы:**
* за каждое **неправильно** преодолённое препятствие — `−1` очко;
* итоговое число очков не может быть меньше 0.

**Успешное преодоление препятствия:**
* Дино начинает прыжок не позже появления препятствия (допустимо одновременно с
  началом препятствия): `x ≤ a`;
* прыжок покрывает всю длину препятствия (можно перепрыгнуть с запасом или
  начать раньше): `x + y ≥ a + len`.

**Трасса некорректна, если** препятствия пересекаются или касаются (одно ещё не
закончилось, а следующее уже началось): для соседних препятствий
`a_{i+1} ≤ a_i + len_i`. В этом случае ответ — 0.

## Формат ввода

```
n
a₁ a₂ … a_n      # неубывающие координаты начал препятствий
b₁ b₂ … b_n      # типы препятствий (1, 2 или 3)
m
x₁ x₂ … x_m      # неубывающие координаты начал прыжков
y₁ y₂ … y_m      # дальности прыжков (1, 2 или 4)
```

## Формат вывода

Целое число — результат Дино после прохождения трассы. Если трасса невалидна —
`0`.

## Примеры

**Пример 1 → `5`**

```
5
10 15 20 25 27
3 1 2 1 1
4
9 14 20 25
1 2 4 4
```

Препятствия: `[10,14)` яма (+5), `[15,16)` камень, `[20,22)` бревно,
`[25,26)` камень, `[27,28)` камень.
Прыжки покрывают: `[9,10]`, `[14,16]`, `[20,24]`, `[25,29]`.
Полностью преодолена только яма (+5); часть препятствий преодолена неправильно
(штрафы), но итог в сумме даёт 5.

**Пример 2 → `0`**

```
3
10 11 12
2 1 2
2
9 12
2 2
```

Препятствие `[10,12)` и следующее с началом `11` пересекаются → трасса
невалидна.

**Пример 3 → `0`**

```
2
14 15
3 1
2
9 12
2 2
```

Препятствие `[14,18)` (яма) и `[15,16)` пересекаются → трасса невалидна.

## Идея решения

1. **Проверка валидности трассы** за `O(n)`: вычислить интервал каждого
   препятствия `[aᵢ, aᵢ + len(bᵢ))` и убедиться, что соседние не касаются и не
   пересекаются (`a_{i+1} > a_i + len_i`). Иначе сразу вывести 0.
2. **Подсчёт очков.** И препятствия, и прыжки заданы в неубывающем порядке
   координат начала. Идём двумя указателями: для каждого препятствия находим
   прыжки, чей воздушный интервал `[xⱼ, xⱼ + yⱼ]` его перекрывает.
   * Если существует прыжок с `xⱼ ≤ aᵢ` и `xⱼ + yⱼ ≥ концаᵢ` — препятствие
     преодолено правильно, прибавляем очки за тип.
   * Иначе (препятствие задето, но не покрыто полностью, либо вообще не
     перепрыгнуто) — штраф `−1`.
3. Итог обрезается снизу нулём.

Линейный проход двумя указателями даёт `O(n + m)`.

## Сложность

| | |
|---|---|
| Время | `O(n + m)` |
| Память | `O(n + m)` |
