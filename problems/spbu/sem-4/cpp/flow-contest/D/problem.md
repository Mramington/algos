# D. Декомпозиция потока

ограничение по времени на тест: 2 секунды  
ограничение по памяти на тест: 256 мегабайт  

Задан ориентированный граф, каждое ребро которого обладает целочисленной пропускной способностью. Найдите максимальный поток из вершины с номером 1 в вершину с номером \(n\) и постройте декомпозицию этого потока.

## Входные данные

Первая строка входного файла содержит \(n\) и \(m\) — количество вершин и количество ребер графа (\(2 \leq n \leq 500\), \(1 \leq m \leq 10000\)).  

Следующие \(m\) строк содержат по три числа: номера вершин, которые соединяет соответствующее ребро графа, и его пропускную способность. Пропускные способности не превосходят \(10^9\).

## Выходные данные

В первую строку выходного файла выведите одно число — количество путей в декомпозиции максимального потока из вершины с номером 1 в вершину с номером \(n\).  

Следующие строки должны содержать описания элементарных потоков, на которые был разбит максимальный. Описание следует выводить в следующем формате: величина потока, количество ребер в пути, вдоль которого течет данный поток, и номера ребер в этом пути. Ребра нужно выводить в порядке прохождения. Ребра нумеруются с единицы в порядке появления во входном файле.

## Пример

| входные данные | выходные данные |
|----------------|------------------|
| 4 5            | 3                |
| 1 2 1          | 1 2 2 5          |
| 1 3 2          | 1 3 2 3 4        |
| 3 2 1          |                  |
| 2 4 2          |                  |
| 3 4 1          |                  |
