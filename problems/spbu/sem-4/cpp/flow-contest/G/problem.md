Задача вида "Project Selection"

# G. Чёрное и белое

ограничение по времени на тест: 1 s.  
ограничение по памяти на тест: 256 МБ  

Дан неориентированный граф без петель и кратных рёбер. Вершины графа бывают двух типов — чёрные и белые. Если чёрная вершина не имеет ни одной соседней белой, то она сразу же исчезает. Аналогично, если белая вершина не имеет чёрных соседей, то она тоже пропадает. Для каждой вершины известна стоимость её удаления. Определите минимальную стоимость удаления всех вершин.

## Входные данные

Два числа \( N \) и \( K \) (\( 1 \leq N \leq 100, 0 \leq K \leq \frac{N(N-1)}{2} \)) — количество вершин и рёбер в графе.  

\( N \) строк по два числа в каждой: \( t, c \) (\( 1 \leq c \leq 10^6 \)) — тип вершины (0 — белая, 1 — чёрная) и стоимость её удаления.  

Далее \( K \) строк по два числа в каждой: \( a, b \) (\( 1 \leq a, b \leq N \)) — номера вершин, соединённых ребром.

## Выходные данные

Одно число — минимальная стоимость удаления всех вершин.

## Пример

| входные данные | выходные данные |
|----------------|------------------|
| 4 3            | 6                |
| 0 4            |                  |
| 0 3            |                  |
| 1 3            |                  |
| 1 5            |                  |
| 1 3            |                  |
| 2 3            |                  |
| 2 4            |                  |
